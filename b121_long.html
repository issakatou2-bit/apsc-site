第1章 顧客体験（CX）と LTV

CX（顧客体験）デザイン
CX
知る・選ぶ・買う・使う・相談するなど、すべての接点での体験
LTV（顧客生涯価値）
一人の顧客が、付き合いの全期間で会社にもたらす利益
顧客ロイヤルティ
その会社や商品を、信頼して選び続ける気持ち
数字で見る
コンバージョン率：購入や申込みなどの成果につながった割合。リテンション率：一定期間後も利用を続けた顧客の割合
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.110〜111（用語例）、Google 広告ヘルプ「コンバージョン率」。顧客体験・各指標の意味は一般的な説明
めたん
第1章は、CX。カスタマーエクスペリエンス、顧客体験よ。
めたん
商品を使うときだけでなく、知る、選ぶ、買う、困ったときに相談する。すべての接点での体験のことね。
ずんだもん
商品がおいしければ、それで十分なのだ。
めたん
レジで長く待たされたり、問い合わせに答えてもらえなかったりすると、また来たい気持ちが下がることもあるわ。
めたん
UXは製品やサービスの利用に関する体験。CXは、会社との接点全体での体験として捉えるわ。
ずんだもん
会社との接点まで含むのだ。
めたん
LTVは、顧客生涯価値。一人のお客さんが、付き合いの全期間で会社にもたらす利益のことよ。
めたん
顧客ロイヤルティは、その会社や商品を信頼して、選び続けてくれる気持ちね。
めたん
コンバージョン率は、訪問などに対して、購入や申込みといった成果が得られた割合よ。
めたん
リテンション率は、一定期間後も利用を続けている顧客の割合よ。
ずんだもん
一回来た人に、また来てもらうのが大事なのだ。

第2章 ペルソナとカスタマージャーニーマップ

ペルソナとカスタマージャーニーマップ（例は説明のための作り話）
  1. ペルソナ：典型的な顧客を、一人の架空の人物として描く（例：30代・会社員・忙しくて朝ごはんを抜きがち）
  2. カスタマージャーニーマップ：その人の行動を時間の順に並べる（知る → 比べる → 買う → 使う → また買う）
  3. それぞれの場面での、気持ちと接点（店・サイト・SNS など）も書く
  4. 気持ちが下がる場面は、問題を調べて改善を検討する手掛かり
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.110〜111（用語例）、Nielsen Norman Group「Journey Mapping 101」。人物と行動の例は架空

めたん

ずんだもん
架空の一人を描くのだ。

ずんだもん
「20代から40代の人」じゃ、だめなのだ？
めたん
それだと広すぎて、だれのために作るのかがぼやけるの。一人に絞るから、具体的に考えられるのよ。
めたん
カスタマージャーニーマップは、そのペルソナの行動を、時間の順に並べたもの。
めたん
知る、比べる、買う、使う、また買う。お客さんの旅を地図にするの。
めたん
それぞれの場面で、何を感じたか、どこで会社と接したかも書き込むわ。
めたん
気持ちが下がる場面は、何が問題なのかを調べ、改善を検討する手掛かりになるわ。

朝ごはんを抜きがちな人なら、駅の売店で買える、と便利なのだ。

第3章 価格の決め方

新しい商品の値段の付け方
最初の値段ねらい
スキミングプライシング最初の値段高くするねらい早期の利益確保を狙う（上澄みをすくう）
ペネトレーションプライシング最初の値段安くするねらい普及を進め、シェアの獲得を狙う（市場に浸透する）
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.110〜111（用語例）、Shopify Help Center「Pricing your products」。価格戦略の意味を要約
めたん
第3章は、価格の決め方。まず、新しい商品を出すときの2つのやり方よ。
めたん
スキミングプライシングは、最初に高い値段を付け、早期の利益確保を狙うやり方よ。
めたん
スキミングは「上澄みをすくう」という意味。高くても買う人から先に売るのよ。
めたん
ペネトレーションプライシングは、最初に安くして、普及とシェアの獲得を狙うの。
めたん
ペネトレーションは「浸透」。市場にしみこませるイメージね。
ほかの価格の決め方（シラバスの用語例から）
ダイナミックプライシング
需要に合わせて値段を変える。例：混む日は高く、すいている日は安く
バリュープライシング
顧客が感じる価値をもとに値段を決める
コストプラス法
かかった費用に、ほしい利益を上乗せする
需要の価格弾力性
価格の変化率に対する、需要量の変化率の大きさ
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.110〜111（用語例）。価格設定・価格弾力性・サブスクリプションの意味と例は一般に確立した説明
めたん
ダイナミックプライシングは、需要に合わせて値段を変えるもの。混む日は高く、すいている日は安く、ね。
ずんだもん
混み具合で値段も変わるのだ。
めたん
バリュープライシングは、お客さんが感じる価値をもとに決めるもの。
めたん
コストプラス法は、かかった費用に、ほしい利益を上乗せして決めるわ。
めたん
需要の価格弾力性は、価格の変化率に対する需要量の変化率の大きさ。大きいほど、価格に敏感なの。
めたん
サブスクリプションモデルは、料金を払って、継続的に商品やサービスの提供を受ける形よ。
ずんだもん
ずんだ餅は、値上げしても買いたいのだ。財布は泣いているのだ！
めたん

第4章 オムニチャネルと Web の戦略

オムニチャネルと Web の戦略
オムニチャネル
店・通販サイト・アプリなどの接点を連携させ、一貫した顧客体験を目指す
SEO
広告以外の検索結果で、サイトを見つけてもらいやすくする工夫
リスティング広告
検索連動型では、検索語に応じて表示される有料の広告
A/B テスト
2つの案を出し分けて、どちらの成果がよいかを比べる
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.110〜111（用語例）、Google 検索セントラル「SEO業者の利用を検討する」。各施策の意味と例は一般的な説明
めたん
第4章は、オムニチャネルとWebの戦略。売る場所と、知ってもらう方法の話よ。
めたん
オムニチャネルは、店や通販サイト、アプリなどの接点を連携させ、一貫した顧客体験を目指すことよ。
めたん
ネットで注文して店で受け取る、店で見た商品をアプリで買う、のようなことができるの。
ずんだもん
ポイントも、どこで買ってもたまるとうれしいのだ。
めたん
SEOは、検索エンジン最適化。広告以外の検索結果で見つけてもらいやすくする工夫よ。
めたん
検索連動型のリスティング広告は、検索語に応じて表示される有料の広告よ。
めたん
A/Bテストは、2つの案を出し分けて、どちらの成果がよいかを数字で比べる方法よ。
めたん
ほかにも、紹介したサイトに成果に応じてお礼を払うアフィリエイトや、最初に見るページを工夫するLPOもあるわ。

過去問に挑戦

ターゲットリターン価格設定の説明はどれか。
  • ア　競合の価格を十分に考慮した上で価格を決定する。
  • イ　顧客層，時間帯，場所など市場セグメントごとに異なった価格を決定する。
  • ウ　目標とする投資収益率を実現するように価格を決定する。
  • エ　リサーチなどによる消費者の値頃感に基づいて価格を決定する。
答えを見るウ　目標とする投資収益率を実現するように価格を決定する。
出典：令和4年度 秋期 応用情報技術者試験 午前 問68

まとめ

ここだけ覚える
  1. CX はすべての接点での体験。LTV は付き合いの全期間でもたらす利益
  2. ペルソナは典型的な顧客の架空の人物。ジャーニーマップはその行動と気持ちを時間の順に
  3. スキミングは高く始めて利益確保を狙い、ペネトレーションは安く始めて普及を狙う
  4. ダイナミックは需要で変える。ターゲットリターンは目標の投資収益率から
  5. オムニチャネルはすべての接点をつなぐ。SEO は検索で上に出す工夫
