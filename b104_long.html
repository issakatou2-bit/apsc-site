第1章 マルウェアの種類

マルウェア（悪意のあるソフトウェア）の種類
コンピュータウイルス
ほかのプログラムやファイルに入り込んで広がる
ワーム
単独で、ネットワークを通じて自分を複製して広がる
トロイの木馬
役に立つソフトを装って入り込む。自分では増えない
ランサムウェア
データを暗号化し、復旧と引き換えに金銭を要求するものがある
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.49〜50（マルウェア・二重脅迫の用語例）。振る舞いと対策は一般的な説明
めたん
第1章はマルウェア。悪意のあるソフトウェアを、まとめてこう呼ぶの。
ずんだもん
ウイルスと同じ意味じゃないのだ？
めたん
ウイルスは、マルウェアの種類の1つよ。ほかにもいろいろあるの。
めたん
コンピュータウイルスは、ほかのプログラムやファイルに入り込んで広がるもの。
めたん
ワームは、ほかのプログラムに寄生せず、単独で自分を複製し、ネットワークを通じて広がるの。
めたん
トロイの木馬は、役に立つソフトのふりをして入り込むもの。
ずんだもん
じゃあトロイの木馬も、どんどん増えて広がるのだ？
めたん
そこが違うの。トロイの木馬は、自分では増えないわ。入り込んで、裏で悪いことをするのが役目よ。
めたん
ランサムウェアには、データを暗号化し、復旧と引き換えに金銭を要求するものがあるわ。
めたん
盗んだデータを公開するぞ、とも脅す、二重脅迫という手口もあるわ。
ずんだもん
お金を払えば、元に戻してくれるのだ？
めたん
お金を払っても、復旧は保証されないわ。バックアップも、被害に備える対策の一つよ。
めたん
ほかにも、利用者の操作をこっそり記録するスパイウェアや、キーボードの入力を記録するキーロガーもあるわ。

第2章 ボットネットと C&C サーバ

ボットネットのしくみ
C&C サーバ
攻撃者が置く司令塔。ボットに指示を出す
ボットネット
感染して、外から操られる PC やサーバ（ボット）の集まり
攻撃
指示を受けて活動する。例：DDoS攻撃、迷惑メールの送信、情報収集
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.49（用語例）、令和5年度 春期 午前 問36（C&Cサーバの役割）。構成・活動例・対策は一般的な説明
めたん
第2章は、ボットネット。マルウェアに感染して、外から操られる機器をボットと呼ぶの。
めたん
ボットに指示を出す司令塔が、C&Cサーバ。コマンド・アンド・コントロールの略よ。
めたん
その指示を受ける、たくさんのボットの集まりが、ボットネット。
めたん
ボットは指示を受け、攻撃や迷惑メールの送信、情報収集などを行うの。
ずんだもん
C&Cサーバは、ボットネットを守る番人なのだ？
めたん
C&Cサーバは、ボットに情報収集や攻撃を指示する側よ。
めたん
感染を防ぐには、OSやソフトを更新し、不審なファイルを開かないことなどが大事よ。
めたん
外から自由に操れるようにするマルウェアは、遠隔操作型ウイルス、RATとも呼ばれるわ。

第3章 パスワードを狙う攻撃

パスワードを狙う攻撃
総当たり（ブルートフォース）攻撃
考えられる文字の組合せを全部試す
辞書攻撃
よく使われる単語や人名のリストで試す
リバースブルートフォース攻撃
パスワードを1つに決めて、ID のほうを次々に変えて試す
パスワードリスト攻撃
ほかのサイトから流出した ID とパスワードの組で試す
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.50（用語例）、令和6年度 秋期 午前 問40（パスワードリスト攻撃）。各手口と対策は一般的な説明
めたん
第3章は、パスワードを狙う攻撃。何を使って、何を変えながら試すかで区別するわ。
めたん
総当たり攻撃は、考えられる文字の組合せを、全部試すもの。ブルートフォース攻撃とも言うわ。
めたん
文字の種類が同じなら、短いパスワードほど組合せは少なくなるの。
めたん
たとえば数字4けたなら、0000から9999までの1万通りよ。
ずんだもん
けたと文字の種類を増やせば、組合せも一気に増えるのだ。
めたん
辞書攻撃は、よく使われる単語や人名のリストで試すもの。
ずんだもん
辞書にある言葉だと、攻撃で試される候補に入りやすいのだ。
めたん
リバースブルートフォース攻撃は、逆向き。パスワードを1つに決めて、IDのほうを次々に変えるの。
めたん
同じIDへの失敗回数を制限しても、複数のIDへの試行を防ぎきれないことがあるの。
めたん
そして、パスワードリスト攻撃。ほかのサイトから流出したIDとパスワードの組を、別のサイトで試すの。
ずんだもん
パスワードのリストを使うなら、辞書攻撃もパスワードリスト攻撃なのだ？
めたん
辞書攻撃は単語などの候補。パスワードリスト攻撃は、流出したIDとパスワードの組を使うの。
めたん
同じパスワードを、いくつものサイトで使い回している人が狙われるのよ。
ずんだもん
ぼく、全部のサイトで「ずんだもち」にしているのだ。
めたん
ふふ、ずんだもち一筋ね。
めたん
サイトごとに違うパスワードを使い、多要素認証も設定するのが対策よ。

第4章 人をだます攻撃

人をだます攻撃
  1. フィッシング：本物そっくりの偽サイトに誘い、ID やパスワードを入力させる（SMS を使うものはスミッシング）
  2. 標的型攻撃：特定の組織などを狙う。仕事のメールを装ってマルウェアを送る手口もある
  3. やり取り型攻撃：ふつうのやり取りを何度か重ねて、信用させてからマルウェアを送る
  4. 水飲み場型攻撃：標的型攻撃の一つ。標的がよく見るWebサイトを改ざんして待ち伏せする
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.50（攻撃手法の用語例）。各手口と対策は一般的な説明
めたん
第4章は、フィッシングと、標的型攻撃の手口を見ていくわ。
めたん
まずフィッシング。本物そっくりの偽サイトに誘って、IDやパスワード、カードの番号を入力させるの。
めたん
SMS、つまりショートメッセージで誘うものは、スミッシングと呼ぶわ。
ずんだもん
宅配便の不在のお知らせが、ぼくのスマホにも来たのだ。
めたん
そういうメッセージのリンクは開かずに、公式のアプリやサイトから確かめるのが安全よ。
めたん
メールの送り主の名前は、簡単にごまかせるの。見た目だけで信じないことね。
めたん
標的型攻撃は、特定の組織などを狙う攻撃。仕事のメールを装ってマルウェアを送る手口もあるわ。
ずんだもん
それなら、だれにでも同じメールを送るのが標的型なのだ？
めたん
逆よ。だれにでも同じものを送るのは、ばらまき型。標的型は、相手に合わせて本物らしく作るの。
めたん
やり取り型攻撃は、標的型の一つ。ふつうの問い合わせを何度かして、信用させてから、マルウェアを送るの。
めたん
水飲み場型攻撃は、待ち伏せ。標的がよく見るWebサイトを改ざんして、訪れた人に感染させるの。
めたん
水飲み場型攻撃も標的型攻撃の一つ。狙った相手が訪れるサイトで待ち伏せするのね。

第5章 Web とサービスを狙う攻撃

Web とサービスを狙う攻撃
クロスサイトスクリプティング（XSS）
Web サイトの弱点を使い、悪いスクリプトを利用者のブラウザで動かす
DoS 攻撃
サービスの利用を妨げる攻撃。大量の通信を送る手口などがある
DDoS 攻撃
複数の機器から行うDoS攻撃。ボットネットが使われることもある
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.50（攻撃手法の用語例）。各手口・被害・可用性との関係は一般的な説明
めたん
第5章は、Webとサービスを狙う攻撃よ。
めたん
クロスサイトスクリプティング、略してXSS。利用者のブラウザで不正なスクリプトを動かす攻撃よ。
めたん
Webサイトの脆弱性を悪用し、cookieなどの情報を盗むことがあるわ。
めたん
DoS攻撃は、サービスの利用を妨げる攻撃。大量の通信を送る手口などがあるわ。
めたん
DDoS攻撃は、複数の機器から行うDoS攻撃。ボットネットが使われることもあるわ。
めたん
DoS攻撃が損なうのは、サービスを利用できるという可用性よ。

過去問に挑戦

パスワードリスト攻撃に該当するものはどれか。
  • ア　一般的な単語や人名からパスワードのリストを作成し，インターネットバンキングへのログインを試行する。
  • イ　想定し得るパスワードとそのハッシュ値との対のリストを用いて，入手したハッシュ値からパスワードを効率的に解析する。
  • ウ　どこかの Web サイトから流出した利用者 ID とパスワードのリストを用いて，他の Web サイトに対してログインを試行する。
  • エ　ピクチャパスワードの入力を録画してリスト化しておき，それを利用することによってタブレット端末へのログインを試行する。
答えを見るウ　どこかの Web サイトから流出した利用者 ID とパスワードのリストを用いて，他の Web サイトに対してログインを試行する。
出典：令和6年度 秋期 応用情報技術者試験 午前 問40

ボットネットにおいて C&C サーバが担う役割はどれか。
  • ア　遠隔操作が可能なマルウェアに，情報収集及び攻撃活動を指示する。
  • イ　攻撃の踏み台となった複数のサーバからの通信を制御して遮断する。
  • ウ　電子商取引事業者などへの偽のデジタル証明書の発行を命令する。
  • エ　不正な Web コンテンツのテキスト，画像及びレイアウト情報を一元的に管理する。
答えを見るア　遠隔操作が可能なマルウェアに，情報収集及び攻撃活動を指示する。
出典：令和5年度 春期 応用情報技術者試験 午前 問36

まとめ

ここだけ覚える
  1. ウイルスは寄生、ワームは単独で増える、トロイの木馬は装って入る
  2. ランサムウェア：暗号化したデータの復旧と引き換えに金銭を要求するものがある
  3. C&C サーバがボットネットに指示 → DDoS など
  4. パスワードリスト攻撃：流出した組を別のサイトで。対策は使い回さない・多要素認証
  5. 標的型は特定の相手を狙う攻撃。水飲み場型はその一つで待ち伏せする
  6. XSSは利用者のブラウザで不正なスクリプトを動かす。DDoSは複数の機器から利用を妨げる
めたん
まとめよ。ウイルスは入り込んで、ワームは単独で増える。トロイの木馬は装って入る。
めたん
ランサムウェアには、暗号化したデータの復旧と引き換えに金銭を要求するものがある。
めたん
C&Cサーバが、ボットネットに指示を出す。DDoS攻撃などに使われる。
めたん
パスワードリスト攻撃は、流出した組を別のサイトで試す。対策は、使い回さないことと、多要素認証。
めたん
標的型は特定の相手を狙う攻撃。水飲み場型は、その一つで待ち伏せする手口。
めたん
XSSは利用者のブラウザで不正なスクリプトを動かす。DDoSは複数の機器から利用を妨げる。

名前を聞けば、手口が分かるようになったのだ！
