第1章 グラフの種類

グラフの種類（シラバスの用語例から）
無向グラフ
辺に向きがない。行き来できる
有向グラフ
辺に向き（矢印）がある
重みつきグラフ
辺に距離や時間などの数がある
完全グラフ
どの2つの頂点も辺で結ばれている
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 1 基礎理論 2. 応用数学（用語例）
めたん
第1章は、グラフ。点と線のつながりを表す図のことよ。
ずんだもん
グラフなら知っているのだ。売上の棒グラフなのだ！
めたん
それは数の大きさを見せるグラフね。ここでのグラフは、頂点と、頂点を結ぶ辺の集まりよ。
めたん
駅を頂点、線路を辺にすれば、路線図もグラフになるわ。
ずんだもん
路線図もグラフになるのだ。
めたん
辺に向きがないのが無向グラフ。どちら向きにも行き来できるの。
めたん
辺に矢印の向きがあるのが有向グラフ。一方通行の道のような形ね。
ずんだもん
SNSのフォローは、片方だけでもできるから、有向グラフなのだ？
めたん
その通り。おたがいに結ぶ友達の関係なら、無向グラフで表せるわ。
めたん
辺に距離や時間の数が付いているのが、重みつきグラフよ。
めたん
どの2つの頂点も、辺で直接結ばれているのが完全グラフ。
もう少しグラフ
  1. 頂点4つの完全グラフ：辺は何本？
  2. 4×3÷2＝6本（1本を両はしから2回数えるので2でわる）
  3. 閉路グラフ：頂点が輪のように1周つながる
  4. 正則グラフ：どの頂点にも、同じ数の辺がつく
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 1 基礎理論 2. 応用数学（用語例）

頂点4つの完全グラフなら、辺は何本かしら。

頂点ごとに3本だから、4かける3で12本なのだ！

頂点が輪のように1周つながったものが、閉路グラフ。
めたん
どの頂点にも同じ数の辺がつくのが、正則グラフよ。

完全グラフも閉路グラフも、どの頂点の辺の数も同じだから、正則グラフでもあるわ。

第2章 最短経路と動的計画法

最短経路（作り話・歩く分数・矢印の向きにだけ進む）
  1. 家→駅 2分　家→店 5分　駅→店 1分
  2. 駅→学校 6分　店→学校 2分
  3. 家→店→学校：5＋2＝7分（辺は2本）
  4. 家→駅→学校：2＋6＝8分
  5. 家→駅→店→学校：2＋1＋2＝5分（いちばん短い）
めたん
第2章は、最短経路問題。重みつきグラフで、いちばん短い道を探すの。
めたん
家から学校へ歩く例よ。説明のための作り話ね。家から駅は2分、家から店は5分、駅から店は1分。
めたん
この例では、画面の矢印の向きにだけ進むものとするわ。
めたん
駅から学校は6分、店から学校は2分。この時間が、辺の重みよ。
ずんだもん
通る辺が少ない方が近いのだ。家から店、店から学校で、辺2本の7分なのだ！
めたん
家から駅、駅から学校も辺2本で、8分ね。
めたん
でも家から駅、駅から店、店から学校なら、2足す1足す2で5分。辺は3本でも、いちばん短いわ。
ずんだもん
辺が多くても5分で着くのだ。
めたん
この例では、辺の数ではなく、重みの合計を比べるの。
動的計画法：小さな答えをメモして使い回す
  1. 駅まで：2分
  2. 店まで：5分と（2＋1）分の短い方 → 3分
  3. 学校まで：（駅2＋6）分と（店3＋2）分の短い方 → 5分
  4. メモした「店まで3分」を使い回した
めたん
道が増えると、全部の道を書き出すのは大変。そこで使えるのが、動的計画法よ。
めたん
大きな問題を小さな問題に分けて、小さな答えをメモしておき、使い回す考え方なの。
めたん
この例では、家、駅、店、学校の順に、各頂点までの最短時間をメモするわ。駅までは2分。
めたん
店までは、直接の5分と、駅を通る2足す1の3分。短い方の3分をメモ。
めたん
学校までは、駅の2分に6分を足した8分と、店の3分に2分を足した5分。短い方の5分ね。
めたん
学校を考えるとき、店までの道を考え直さずに、メモの3分を使ったでしょ。これが使い回しよ。
ずんだもん
メモする順番も大事なのだ？
めたん
ええ。次の計算に必要な答えを先に求めておくの。この例では、学校より先に駅と店ね。

第3章 最適化問題

ナップサック問題（作り話：4kgまで・各品物1個まで）
  1. カメラ 3kg・価値50　本 2kg・価値30　水筒 2kg・価値30
  2. 価値の大きい順：カメラを入れると残り1kg → 合計50
  3. 本と水筒：2＋2＝4kg → 合計60（こちらが最大）
  4. 品物がn個なら選び方は2のn乗通り（重さの上限を超える選び方も含む）
めたん
第3章は、最適化問題。決まりを守って、いちばんよい答えを探す問題よ。
めたん
まずナップサック問題。作り話の4kgまで入る袋に、各品物を1個まで入れて、価値の合計を最大にするの。
めたん
カメラは3kgで価値50。本と水筒は、どちらも2kgで価値30。
ずんだもん
価値の大きいカメラから入れるのだ！これで50なのだ！
めたん
カメラを入れると、残りは1kg。本も水筒も、もう入らないわ。
めたん
本と水筒なら2足す2で4kg、ちょうど入って、価値は60。こちらが最大よ。
ずんだもん
4キロで価値60なのだ。
めたん
各品物を入れるか入れないかで、n個なら2のn乗通り。重さの上限を超える選び方も含む数よ。
ずんだもん
ぼくの袋なら、ずんだ餅だけを4kg入れるのだ！
めたん
ふふ、価値は人それぞれね。
最適化問題の仲間（シラバスの用語例から）
組合せ最適化問題
選び方・並べ方の中からいちばんよいものを探す
ナップサック問題
重さの上限の中で、価値の合計を最大にする

めたん
選び方や並べ方の中から、いちばんよいものを探すのが、組合せ最適化問題。
めたん
ナップサック問題は、選び方の組合せ最適化ね。
めたん
巡回セールスマン問題は、全部の町を1回ずつ回って出発点に戻る、いちばん短い道順を探す問題よ。
巡回の数（全町間を移動可・往復同距離・出発点固定・逆回りは同一）
  1. 町4つ：3×2×1÷2＝3通り
  2. 町5つ：4×3×2×1÷2＝12通り
  3. 町10個：181440通り
めたん
どの町の間も移動でき、往復の距離は同じとするわ。出発点を固定し、逆回りは同じと数えるの。
めたん
町が4つなら、3かける2かける1を2でわって、3通り。
ずんだもん
4つの町なら3通りなのだ。
めたん
町が5つなら、12通り。
ずんだもん
それなら町が10個でも、全部ためせばいいのだ！
めたん
町が10個だと、18万1440通り。数がものすごい速さで増えるの。
めたん
最後に、連続最適化問題。量を連続した数で決める問題で、線形計画法が代表よ。
めたん
線形計画法は、条件を1次の等式や不等式で表し、1次式で表した目的の値を最大や最小にする方法よ。
めたん
例えば、材料に限りがある中で、2つの製品をどれだけ作れば利益が最大か、という問題よ。作り話ね。
めたん
作業の順序と所要時間から全体の工期を考えるPERTも、この分野の内容よ。

第4章 待ち行列と M/M/1

待ち行列の言葉（シラバスの用語例から）
  1. 到着間隔：客が来る間隔。平均到着率は、1分あたり何人来るか
  2. サービス時間：1人の処理にかかる時間。平均サービス率は、1分あたり何人さばけるか
  3. 利用率＝平均到着率 ÷ 平均サービス率（＝平均到着率 × 平均サービス時間）
  4. M/M/1：一定時間の到着人数はポアソン分布、サービス時間は指数分布。窓口は1つ
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 1 基礎理論 2. 応用数学（用語例）
めたん
第4章は、待ち行列。窓口に並ぶ列を、数で考えるの。
めたん
客が来る間隔が到着間隔。1分あたり平均何人来るかが、平均到着率よ。
めたん
1人の処理にかかる時間がサービス時間。1分あたり平均何人さばけるかが、平均サービス率。
めたん
利用率は、平均到着率を平均サービス率でわった値。窓口が働いている時間の割合よ。
めたん
平均到着率に、平均サービス時間をかけても、同じ値になるわ。
めたん
M/M/1は、客の来方もサービス時間もばらばらで、窓口が1つの形。
めたん
一定時間の到着人数はポアソン分布、処理時間は指数分布に従うの。
めたん
この計算では、待てる人数に上限がなく、利用率が100%未満の場合を考えるわ。
M/M/1の平均待ち時間（処理前の待ち・人数上限なし・利用率100%未満）
  1. 平均待ち時間＝利用率 ÷（1－利用率）× 平均サービス時間
  2. 平均4分に1人来る → 平均到着率1/4人/分。平均サービス時間3分
  3. 利用率＝1/4 × 3＝0.75
  4. 平均待ち時間＝0.75 ÷ 0.25 × 3分＝9分
  5. 到着から処理完了までの平均時間：9＋3＝12分
めたん
M/M/1の平均待ち時間は、利用率を、1ひく利用率でわって、平均サービス時間をかけるの。
めたん
窓口が1つの店の作り話よ。客は平均4分に1人来て、1人の処理は平均3分。
めたん
利用率は、4分の1かける3で、0.75。
ずんだもん
1人3分なら、前の人を待つのも3分くらいなのだ！
めたん
0.75を0.25でわると3。3かける3分で、平均待ち時間は9分よ。
めたん
客がばらばらに来るから、たまたま続けて来たときに列が伸びるの。
めたん
平均待ち時間9分に平均処理時間3分を足すと、到着から処理完了までは平均12分よ。
利用率と平均待ち時間（平均サービス時間の何倍か）
  1. 利用率 50%：0.5÷0.5＝1倍
  2. 利用率 75%：0.75÷0.25＝3倍
  3. 利用率 80%：0.8÷0.2＝4倍
  4. 利用率 90%：0.9÷0.1＝9倍
めたん
利用率を変えると、待ち時間はどうなるかしら。
めたん
50%なら1倍、75%なら3倍。
めたん
80%なら4倍、90%なら9倍。1に近づくほど、急に伸びるの。
ずんだもん
利用率が100%なら、10倍くらいなのだ？
めたん
利用率100%では、この式は使えないわ。平均待ち時間が有限の値に落ち着かないの。
めたん
乱数でばらばらな到着を作って、列の伸び方をためすシミュレーションも、シラバスにある考え方よ。

まとめ

ここだけ覚える
  1. 無向・有向・重みつき・完全・閉路・正則グラフ
  2. 重みつきグラフの最短経路：辺の重みの合計を比べる
  3. 動的計画法：小さな答えをメモして使い回す
  4. ナップサック・巡回セールスマンは組合せ最適化。数がすぐ増える
  5. 利用率＝平均到着率 × 平均サービス時間
  6. M/M/1の平均待ち時間＝利用率÷（1－利用率）×平均サービス時間
