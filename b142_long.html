第1章 位取りと重み

位取りと重み
  1. 10進数：桁の重みは 1、10、100 …（10 の何乗）
  2. 2進数：桁の重みは 1、2、4、8 …（2 の何乗）
  3. 例：1011（2進）＝ 8 ＋ 0 ＋ 2 ＋ 1 ＝ 11
  4. 基数：1 桁で使える数字の個数（2進数は 0 と 1 の 2 個）
めたん
まず10進数。352は、3が百の位、5が十の位、2が一の位よ。
ずんだもん
300と50と2で、352なのだ。
めたん
その百、十、一を、桁の重みと言うわ。10進数の重みは、10の何乗かになっているの。
めたん
2進数は、使う数字が0と1だけ。重みは右から1、2、4、8と、2倍ずつ増えるの。
ずんだもん
右から2倍ずつ重くなるのだ。
めたん
例えば2進数の1011。重みは左から8、4、2、1。1が立っている桁の重みを足すの。
めたん
8足す2足す1で、11。10進数の11よ。
ずんだもん
1011だから、千十一なのだ！
めたん
それは10進数の読み方ね。2進数では、重みを足して11よ。
めたん
1桁で使える数字の個数を、基数と言うわ。2進数の基数は2、10進数は10よ。
ずんだもん
使える数字がn個なら、n進数なのだ？
めたん
そう。重みはnの何乗かになる。各桁の数字に重みをかけて足すのは、どの基数でも同じよ。

第2章 10進数から2進数へ

10進数から2進数へ
  1. 整数：2 で割って、余りを書いていく
  2. 例：13 → 余り 1、0、1、1 → 下から読んで 1101
  3. 小数：2 をかけて、整数の部分を上から並べる
  4. 例：0.625 → 1、0、1 → 0.101
  5. 0.1 は 0.000110011… と終わらない
めたん
次は逆。10進数の整数を2進数にするには、2で割って、余りを書いていくの。
めたん
13でやるわ。13わる2は6余り1。6わる2は3余り0。
めたん
3わる2は1余り1。1わる2は0余り1。商が0になったら止めるわ。
めたん
余りを下から読むと、1101。これが13の2進数よ。
ずんだもん
上から読んで、1011なのだ！
めたん
逆よ。最初の余りが一の位、いちばん右に来るの。だから下から読むのよ。
めたん
確かめると、8足す4足す1で13。重みで戻せば、まちがいに気付けるわ。
ずんだもん
行って、戻って、確かめる。往復切符なのだ。
めたん
ふふ、片道で終わらせないのね。
めたん
小数は、2をかけていくの。出てきた整数の部分を、上から順に並べるわ。
ずんだもん
あっ、小数は2をかけるのだ。
めたん
0.625なら、2倍で1.25。整数の1を取って、残りは0.25。
めたん
0.25の2倍は0.5で、0。0.5の2倍は1.0で、1。だから0.101よ。
ずんだもん
小数は上から読むのだ。整数と逆なのだ。
めたん
小数点のすぐ右は、2分の1の位。最初に出た数字が、そこに入るからよ。
めたん
ただし10進数の0.1は、2進数では0.000110011…と、終わらないの。
ずんだもん
0.1でも終わらないのだ。
めたん
2進数の小数を有限の桁で表すと、丸めなどによる誤差が出ることがあるの。

第3章 8進数と16進数

8進数と16進数
  1. 8進数へ：2進数の整数部分を右から3桁ずつ区切る
  2. 例：101011 → 101｜011 → 53（8進）
  3. 16進数へ：整数部分を右から4桁ずつ。10〜15はA〜F
  4. 例：10101111 → 1010｜1111 → AF ＝ 175
  5. n進数：使える数字が n 個、重みは n の何乗
めたん
2進数は桁が長くなる。そこで8進数や16進数で、短く書くことがあるの。
めたん
8は2の3乗。だから2進数の整数部分を、右から3桁ずつ区切れば、8進数になるわ。
めたん
101011なら、101と011。101は5、011は3。だから8進数の53よ。
ずんだもん
上から3桁ずつ区切っても、いいのだ？
めたん
右からよ。桁の数が3で割り切れないとき、左から区切ると重みがずれるの。
めたん
足りない分は、左端に0を足してそろえるわ。
めたん
16は2の4乗。16進数にするときは、整数部分を右から4桁ずつ区切るの。
めたん
1桁に16種類の数字が要るから、10から15は、AからFで表すわ。
めたん
10101111なら、1010と1111。1010は10でA、1111は15でF。だからAFよ。
めたん
10進数に直すと、10かける16、足す15で、175になるわ。

第4章 ビット数と表せる数

ビット数と表せる数
  1. n ビットで 2 の n 乗通り（8 ビットで 256 通り）
  2. 符号なし整数：0 〜 2 の n 乗 − 1（8 ビットで 0〜255）
  3. 2の補数で負の数を表す：桁数を固定し、絶対値のビットを反転して1を足す
  4. 8 ビットの 2 の補数：−128 〜 127
  5. 左に1ビットシフトし、右端に0を入れる → 2倍（あふれなければ）
めたん
2進数の1桁を、1ビットと言うわ。1ビットで、0か1の2通り。
めたん
nビットなら、2のn乗通り。8ビットなら、2の8乗で256通りよ。
ずんだもん
8ビットなら、8かける2で16通りなのだ！
めたん
1ビット増えるごとに、2倍になるの。2を8回かけて、256よ。
めたん
符号なし整数なら、0から2のn乗ひく1まで。8ビットなら0から255よ。
ずんだもん
256通りなのに、最後は255なのだ？
めたん
0から数えるからよ。0も1通りに入るの。
ずんだもん
0を数え忘れて、おやつを1個損したことがあるのだ。
めたん
ふふ、それは悔しいわね。
めたん
2の補数で負の数を表すには、桁数を固定し、絶対値のビットを反転して1を足すの。
ずんだもん
反転したら1を足すのだ。
めたん
8ビットで6は、00000110。反転すると、11111001。
めたん
1を足して、11111010。これがマイナス6よ。
めたん
8ビットの2の補数で表せるのは、マイナス128から127までよ。
ずんだもん
負の数が128通り、0以上の数も128通りなのだ。
めたん
左シフトでは、右端に0を入れるの。左に1ビットずらすと、あふれなければ2倍よ。
めたん
符号なしの5ビットで13は01101。左へ1ビットずらすと11010で26よ。
ずんだもん
重みが全部、2倍になるからなのだ。

過去問1 令和5年度秋期 問1

2 桁の 2 進数 x₁x₂ が表す整数を x とする。2 進数 x₂x₁ が表す整数を，x の式で表したものはどれか。ここで，int(r) は非負の実数 r の小数点以下を切り捨てた整数を表す。
  • ア　2x＋4int(x/2)
  • イ　2x＋5int(x/2)
  • ウ　2x－3int(x/2)
  • エ　2x－4int(x/2)
答えを見るウ　2x－3int(x/2)
出典：令和5年度 秋期 応用情報技術者試験 午前 問1（式を1行で表記）
めたん
ここから過去問。1問目は、令和5年度秋期の午前、問1よ。
めたん
2桁の2進数x₁x₂の値をxとする。入れかえたx₂x₁を、xの式で表すと？5秒で考えてみて。
めたん
答えはウ、2x−3int(x/2)よ。
解き方
  1. x ＝ 2x₁ ＋ x₂（上の桁の重みは 2）
  2. x₁ ＝ int(x/2)、x₂ ＝ x − 2int(x/2)
  3. x₂x₁ ＝ 2x₂ ＋ x₁ ＝ 2x − 4int(x/2) ＋ int(x/2)
  4. ＝ 2x − 3int(x/2) → ウ
  5. 確かめ：x₁x₂ ＝ 10 なら x ＝ 2、01 は 1。ウは 4 − 3 ＝ 1
めたん
上の桁x₁の重みは2、下の桁x₂の重みは1。だからxは、2x₁足すx₂。
めたん
x₁は、xを2で割った整数の部分で、int(x/2)。
めたん
x₂はその余りで、xひく2かけるint(x/2)よ。
めたん
入れかえたx₂x₁は、2x₂足すx₁。ここに、いまの2つを入れるわ。
めたん
2xひく4int(x/2)、足すint(x/2)で、2xひく3int(x/2)。ウね。
めたん
数を入れて確かめるわ。x₁x₂が10なら、xは2。入れかえた01は1よ。
めたん
xが2なら、int(x/2)は1。ウは4ひく3で1。アは8、イは9、エは0。合うのはウだけよ。

過去問2 令和元年度秋期 問1

あるホテルは客室を 1,000 部屋もち，部屋番号は，数字 4 と 9 を使用しないで 0001 から順に数字 4 桁の番号としている。部屋番号が 0330 の部屋は，何番目の部屋か。
  • ア　204
  • イ　210
  • ウ　216
  • エ　218
答えを見るウ　216
出典：令和元年度 秋期 応用情報技術者試験 午前 問1
めたん
2問目は、令和元年度秋期の午前、問1。最初の部屋番号の問題よ。
めたん
4と9を使わず、0001から順に4桁の番号。0330は何番目の部屋か。5秒で考えてみて。
めたん
答えはウ、216番目よ。
解き方
  1. 使える数字：0〜3 と 5〜8 の 8 個 → 8進数
  2. 読みかえ：5→4、6→5、7→6、8→7（0〜3 はそのまま）
  3. 0330 → 8進数の 330
  4. 3 × 64 ＋ 3 × 8 ＋ 0 ＝ 192 ＋ 24 ＝ 216 → ウ
めたん
使える数字は、0から9のうち、4と9を除いた8個。数字が8個だから、8進数と同じ数え方よ。
ずんだもん
使える数字が8個なのだ。
めたん
数字を0から7に読みかえるわ。5は4、6は5、7は6、8は7。0から3はそのまま。
めたん
0330は、3と3と0だから、読みかえても同じ。8進数の330になるわ。
めたん
8進数の重みは、64、8、1。3かける64は192、3かける8は24。足して216。
めたん
0001が1番目だから、8進数に読みかえた値が、そのまま順番になるの。
ずんだもん
4と9の2つを抜くから、330ひく2、にはならないのだ？
めたん
ならないわ。どの桁でも抜けるから、上の桁ほど、ずれが大きくなるの。

過去問3 令和4年度秋期 問1

a を正の整数とし，b ＝ a² とする。a を 2 進数で表現すると n ビットであるとき，b を 2 進数で表現すると最大で何ビットになるか。
  • ア　n＋1
  • イ　2n
  • ウ　n²
  • エ　2ⁿ
答えを見るイ　2n
出典：令和4年度 秋期 応用情報技術者試験 午前 問1
めたん
3問目は、令和4年度秋期の午前、問1よ。
めたん
aはnビットの正の整数。bはaの2乗。bは最大で何ビットか。5秒で考えてみて。
めたん
答えはイ、2nビットよ。
解き方
  1. n ビットの最大は 2 の n 乗 − 1 → a ＜ 2 の n 乗
  2. a² ＜ 2 の n 乗 × 2 の n 乗 ＝ 2 の 2n 乗
  3. n≧2なら (2ⁿ−1)² ≧ 2^(2n−1) → 最大2nビット → イ（n＝1は1ビット）
  4. 例：4 ビットの最大 15 → 15² ＝ 225 ＝ 11100001（8 ビット）
めたん
nビットで表せる最大は、2のn乗ひく1。つまりaは、2のn乗より小さいわ。
めたん
だからaの2乗は、2のn乗かける2のn乗より小さい。これは2の2n乗よ。
ずんだもん
2のn乗の2乗は、2のn²乗なのだ！
めたん
底が同じ累乗の掛け算では、指数を足すの。n足すnで、2nよ。
めたん
nが2以上なら、最大のaの2乗は2の2n−1乗以上。だから最大2nビットよ。
めたん
nが1なら、aもbも1で1ビット。この場合だけは例外よ。
めたん
確かめるわ。4ビットの最大15を2乗すると225。2進数で11100001、ちょうど8ビットよ。

過去問4 令和2年度10月 問1

正の整数の 10 進表示の桁数 D と 2 進表示の桁数 B との関係を表す式のうち，最も適切なものはどれか。
  • ア　D ≒ 2 log₁₀ B
  • イ　D ≒ 10 log₂ B
  • ウ　D ≒ B log₂ 10
  • エ　D ≒ B log₁₀ 2
答えを見るエ　D ≒ B log₁₀ 2
出典：令和2年度 10月 応用情報技術者試験 午前 問1
めたん
4問目は、令和2年度10月試験の午前、問1。
めたん
正の整数の、10進数の桁数Dと、2進数の桁数B。その関係の式はどれか。5秒で考えてみて。
めたん
答えはエよ。
解き方
  1. 数の値をNとすると、2のB−1乗 ≦ N ＜ 2のB乗
  2. 同じNについて、10のD−1乗 ≦ N ＜ 10のD乗
  3. 10を底とする対数で考えると、桁数の関係は D ≒ B log₁₀2
  4. log₁₀ 2 ≒ 0.3：2 の 10 乗 ＝ 1024 ≒ 1000 → エ
めたん
B桁の2進数の値は、2のB−1乗以上、2のB乗未満よ。
めたん
同じ数を10進数でD桁と書くなら、10のD−1乗以上、10のD乗未満よ。
めたん
10を底とする対数で考えると、DはおよそBかけるlog₁₀2よ。
めたん
log₁₀2は約0.3。2の10乗は1024で、ほぼ1000でしょう。
めたん
2進数で10桁増えると、10進数では約3桁増える目安になるの。
めたん
数でも確かめるわ。Bに20を入れると、エは約6、アは約2.6。イとウは40を超えるわ。
めたん
2進数でちょうど20桁の正の整数は、約52万から約105万。6桁か7桁だからエね。
ずんだもん
ウは、0.3じゃなくて、約3.3をかけていたのだ。

まとめ

ここだけ覚える
  1. 2進数→10進数：1 の桁の重み（1、2、4、8 …）を足す
  2. 10進数→2進数：整数は 2 で割り余りを下から、小数は 2 をかけて上から
  3. 2進数の整数部分を右から区切る：3桁ずつで8進数、4桁ずつで16進数
  4. nビットで2のn乗通り。符号なし整数なら0〜2のn乗−1
  5. 式で迷ったら、数を入れて確かめる
めたん
まとめよ。2進数を10進数にするときは、1が立っている桁の重みを足す。
めたん
10進数を2進数にするときは、整数は2で割って余りを下から、小数は2をかけて上から。
めたん
2進数の整数部分は、右から3桁ずつなら8進数、4桁ずつなら16進数に直せる。
めたん
nビットで2のn乗通り。符号なし整数なら、0から2のn乗ひく1まで。
めたん
そして、式で迷ったら、小さな数を入れて確かめてね。
ずんだもん
重みを足して、数を入れて確かめるのだ！
