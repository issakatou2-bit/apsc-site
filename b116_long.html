第1章 ネットワークの運用管理

ネットワーク運用管理の3つ
構成管理
どんな機器が、どうつながり、どのバージョンかを記録して、変更も残す
障害管理
見つける → 切り分ける → 原因を特定 → 直す → 記録。死活監視で止まりに気付く
性能管理
トラフィックの量を見張り、遅くなっていないかを見る
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.46（構成・障害・性能管理と用語例）。各管理の意味と切分けの例は一般的な説明
めたん
第1章は、ネットワークの運用管理。大きく3つに分けられるの。
めたん
一つ目は構成管理。どんな機器が、どうつながっていて、どのバージョンで動いているかを記録するの。
めたん
機器を入れ替えたり設定を変えたりしたら、その変更も記録しておくわ。
ずんだもん
地図がないと、どこを調べればいいか分からないのだ。
めたん
二つ目は障害管理。止まったことに気付いて、原因を探して、直して、記録するの。
めたん
気付くための方法の一つが、死活監視。機器が生きているかを、定期的に確かめるのよ。
ずんだもん
機器の生存確認なのだ。
めたん
そして大事なのが、障害の切り分け。どこまでは正常で、どこから先がおかしいかを、順に絞り込むの。
ずんだもん
調べた結果を使って、原因がありそうな所を絞り込むのだ。
めたん
たとえば、自分のPCの設定、近くのルータ、その先のインターネット、と近い所から順に確かめていくの。
めたん
直したら、何が起きて、どう直したかを記録する。次に同じことが起きたとき、早く直せるわ。
めたん
三つ目は性能管理。トラフィックの量を見張って、遅くなっていないか、混みすぎていないかを見るわ。

第2章 調べる道具

調べる道具（シラバスの用語例から）
ping
相手に届くか、返事が来るか（ICMP を使う）
traceroute
途中のルータからの応答を使い、相手までの経路を調べる
arp
記録済みのIPv4アドレスとMACアドレスの対応表を見る
その他
ifconfig・ip（設定を見る）、netstat・ss（つながりを見る）、dig（DNS に聞く）、tcpdump・Wireshark（パケットを見る）
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.46（用語例）、令和5年度 秋期 午前 問33（pingとICMP）、令和6年度 秋期 午前 問36（arp）。各道具の動作・制約は一般的な説明
めたん
第2章は、調べるコマンドや、パケットアナライザーを見ていくわ。
めたん
まずping。相手に小さなメッセージを送って、返事が来るかを見るの。
めたん
pingが使うのは、ICMPというプロトコルよ。
ずんだもん
pingの返事が来たら、ネットは全部だいじょうぶなのだ。
めたん
そうとは限らないの。届くことは分かっても、Webやメールのしくみが動いているかは、別に確かめるのよ。
めたん
逆に、機器の設定でpingに答えないようにしていることもあるわ。
ずんだもん
応答しない設定もあるのだ。
めたん
tracerouteは、途中のルータからの応答を使って、相手までの経路を調べる道具よ。
めたん
応答がない所が、障害の場所とは限らないけれど、切り分けの手掛かりになるわ。
ずんだもん
どうやって、通ったルータが分かるのだ？
めたん
IPパケットには、ルータを通るたびに減る値があるの。
めたん
その値を1、2、3と増やして送り、値が尽きた所のルータからの応答を調べるのよ。
めたん
arpは、記録済みのIPv4アドレスとMACアドレスの対応表を見るコマンドよ。
めたん
ほかにも、自分の設定を見るifconfigやip、つながりの状態を見るnetstatやss。
めたん
DNSに名前を問い合わせるdig、流れるパケットを記録して見る、tcpdumpやWiresharkもあるわ。
ずんだもん
コマンドの名前、早口言葉みたいなのだ。
めたん
ふふ、3回言えたら合格ね。

第3章 SNMP で集めて管理

SNMP
SNMP 管理ステーション
機器をまとめて管理する側
SNMP エージェント
管理される機器の中で動き、情報を持っている
MIB（管理情報ベース）
エージェントが持つ管理情報の集まり
やり取り
get要求で読む・書込みの要求で設定を変更する・trapで機器から異常などを通知する
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.46（用語例）、RFC 1157（読取り・書込み・通知）。シラバスは書込みをput要求と表記し、仕様のメッセージ名はSetRequest。管理情報・性能管理の説明は一般的な説明
めたん
第3章はSNMP。たくさんのネットワーク機器を、まとめて管理するためのプロトコルよ。
めたん
管理する側が、SNMP管理ステーション。マネージャとも呼ぶわ。
めたん
管理される機器の中で動くのが、SNMPエージェント。
めたん
エージェントが持っている管理情報の集まりが、MIB。通信の量やエラーの数などが入っているの。
めたん
たとえば、ポートごとの送信データ量を定期的に集めると、通信量の変化を調べられるわ。
ずんだもん
通信量の変化が見えるのだ。
めたん
管理ステーションは、get要求で情報を読み、書込みの要求で設定を変更するのよ。
ずんだもん
じゃあ、いつも管理ステーションから聞きに行くのだ？
めたん
trapは、エージェントから管理ステーションへ、異常などの出来事を通知するのよ。
ずんだもん
SNMPで集めた数字を見れば、性能管理もできるのだ。

第4章 ネットワークの仮想化

ネットワークの仮想化
トンネリング
パケットを別のパケットで包んで運ぶ。VPN などで使う
SDN と OpenFlow
転送する機能と、制御する機能を分け、制御をソフトウェアでまとめて行う
NFV
ルータやファイアウォールの機能を、専用機器ではなく汎用サーバのソフトウェアで動かす
SD-WAN
拠点どうしをつなぐ WAN を、ソフトウェアでまとめて制御する
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.46（用語例）、令和4年度 春期 午前 問35（OpenFlowを使ったSDN）。各技術の意味と用途は一般に確立した説明
めたん
第4章は、ネットワークの仮想化。物理的な構成と、論理的なネットワークや機能を切り離す考え方よ。
めたん
トンネリングは、パケットを別のパケットで包んで運ぶこと。出口で包みを外して、中身を届けるの。
ずんだもん
包んで運んで、出口で外すのだ。
めたん
VPNなどで、離れた拠点間の通信にも使われているわ。
めたん
SDNは、ネットワーク機器の「運ぶ働き」と「どう運ぶかを決める働き」を分けるしくみ。
めたん
決める働きを、コントローラというソフトウェアにまとめて、たくさんの機器を一度に制御するの。
めたん
コントローラと機器のやり取りの決まりの一つが、OpenFlowよ。
めたん
通信の流れを、ソフトウェアから柔軟に変えられるのが、SDNのよいところよ。
めたん
NFVは、ルータやファイアウォールの働きを、専用の機器ではなく、ふつうのサーバのソフトウェアで動かすもの。
ずんだもん
SDNとNFVは、同じものなのだ？
めたん
SDNは制御と転送を分けること。NFVはネットワーク機能をソフトウェアで動かすことよ。
めたん
SD-WANは、本社と支店などをつなぐWANを、ソフトウェアでまとめて制御するしくみよ。
めたん
いくつもの回線を、通信の種類に合わせて使い分けたりできるわ。

過去問に挑戦

IPv4 の LAN に接続されているプリンターの MAC アドレスを，同一 LAN 上の PC から調べるときに使用するコマンドはどれか。ここで，PC はこのプリンターを直前に使用しており，プリンターの IP アドレスは分かっているものとする。
  • ア　arp
  • イ　ipconfig 又は ifconfig
  • ウ　netstat
  • エ　ping
答えを見るア　arp
出典：令和6年度 秋期 応用情報技術者試験 午前 問36
めたん
過去問に挑戦。1問目は、令和6年度秋期の午前、問36よ。
めたん
同じLANのプリンターのMACアドレスを、PCから調べるコマンドはどれか。
めたん
PCは直前にプリンターを使っていて、IPアドレスは分かっているわ。
めたん
5秒で考えてみて。
めたん
答えはア、arp。直前に通信した相手のIPアドレスとMACアドレスの対応が、表に残っているの。
めたん
イは自分の設定、ウはつながりの状態、エは届くかどうか。相手のMACアドレスは分からないわ。
ずんだもん
「直前に使った」というのが、ヒントだったのだ。
OpenFlow を使った SDN（Software-Defined Networking）に関する記述として，適切なものはどれか。
  • ア　インターネットのドメイン名を管理する世界規模の分散データベースを用いて，IP アドレスの代わりに名前を指定して通信できるようにする仕組み
  • イ　携帯電話網において，回線交換方式ではなく，パケット交換方式で音声通話を実現する方式
  • ウ　ストレージ装置とサーバを接続し，WWN（World Wide Name）によってノードやポートを識別するストレージ用ネットワーク
  • エ　データ転送機能とネットワーク制御機能を論理的に分離し，ネットワーク制御を集中的に行うことを可能にしたアーキテクチャ
答えを見るエ　データ転送機能とネットワーク制御機能を論理的に分離し，ネットワーク制御を集中的に行うことを可能にしたアーキテクチャ
出典：令和4年度 春期 応用情報技術者試験 午前 問35
めたん
2問目は、令和4年度春期の午前、問35。
めたん
OpenFlowを使ったSDNに関する記述として、適切なものはどれか。5秒よ。
めたん
答えはエ。データを運ぶ働きと、制御する働きを分けて、制御をまとめて行うしくみよ。
めたん
アはDNS、イは携帯電話網で音声をパケットで送る方式、ウはストレージ用のネットワークの話ね。
ずんだもん
「分けて、まとめる」が、SDNの合い言葉なのだ。

まとめ

ここだけ覚える
  1. 運用管理は、構成・障害・性能の3つ。障害は切り分けが大事
  2. ping は届くか（ICMP）、traceroute は通り道、arp は IP と MAC の対応
  3. SNMP：管理ステーションとエージェント、情報は MIB、trap は機器から知らせる
  4. SDNは制御と転送を分ける。OpenFlowはコントローラと転送機器の通信規約の一つ
  5. NFV は機能をソフトウェアに、SD-WAN は WAN をソフトウェアで
出典：IPA 応用情報技術者試験 シラバス Ver.7.2 p.46、令和6年度 秋期 午前 問36、令和4年度 春期 午前 問35、令和5年度 秋期 午前 問33。用語の意味・動作・制約は一般的な説明
めたん
まとめよ。運用管理は、構成、障害、性能の3つ。障害は切り分けが大事。
めたん
pingは届くか、tracerouteは通り道、arpはIPとMACの対応。
めたん
SNMPは、管理ステーションとエージェント。情報はMIB、trapは機器から知らせる。
めたん
SDNは制御と転送を分ける。OpenFlowは、コントローラと転送機器の通信規約の一つよ。
めたん
NFVは機能をソフトウェアに、SD-WANはWANをソフトウェアで制御。
ずんだもん
つながらないときは、pingとtracerouteで順番に切り分けるのだ！
