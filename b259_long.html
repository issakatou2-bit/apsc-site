再帰：呼び出す順と戻る順

再帰は「同じ関数の別の呼び出し」
再帰
関数が自分自身を呼び出す
基底条件
再帰呼び出しをせずに答えを返す条件
基底条件へ近づける

一般に確立した知識。階乗の定義はIPA 令和7年度 春期 午前 問7とも照合
めたん

過去問に挑戦：階乗の定義

fact(n) は非負の整数nの階乗を返す。再帰的な定義はどれか。
  • ア　if n=0 then return 0 else return n×fact(n−1)
  • イ　if n=0 then return 0 else return n×fact(n＋1)
  • ウ　if n=0 then return 1 else return n×fact(n−1)
  • エ　if n=0 then return 1 else return n×fact(n＋1)
答えを見るウ　if n=0 then return 1 else return n×fact(n−1)
出典：令和7年度 春期 応用情報技術者試験 午前 問7（問題文を要約、記号・空白の体裁を変更）

めたん
