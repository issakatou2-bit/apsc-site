第1章 アローダイアグラムの読み方

アローダイアグラムの読み方
  1. 矢印＝作業（作業名と所要日数）
  2. 丸＝結合点（作業の区切り）
  3. 出る作業は、入る作業が全部終わってから
  4. 点線＝ダミー作業（0日。順番だけ）
めたん
第1章は、アローダイアグラムの読み方。
めたん
矢印の1本が、作業1つ。矢印に作業名と所要日数を添えるわ。
めたん
丸は結合点。作業と作業の区切りで、番号を付けておくの。
ずんだもん
丸は作業の区切りなのだ。
めたん
結合点から出る作業は、そこに入る作業が全部終わってから始められる。
ずんだもん
1本でも終わっていなかったら、待つのだ？
めたん
そう。ここが、あとで大きい方を選ぶ理由になるわ。
めたん
点線の矢印はダミー作業。日数は0で、順番だけを表すの。
ずんだもん
0日なら、無視してもいいのだ！
めたん
点線も順番を表すの。先の作業は、点線の出発点に入る作業が全部終わるまで待つわ。
例（説明のための作り話）
  1. A：1 → 2　3日
  2. B：1 → 3　5日
  3. C：2 → 4　6日
  4. D：3 → 4　2日
  5. E：4 → 5　3日
めたん
例を1つ使うわ。これは説明のための作り話よ。
めたん
Aは結合点1から2へ3日。Bは1から3へ5日。
めたん
Cは2から4へ6日、Dは3から4へ2日。結合点4で合流するわ。
めたん
最後にEが4から5へ3日。結合点5で全部終わりよ。
ずんだもん
全部足すと、3＋5＋6＋2＋3で19日なのだ！
めたん
それが最初の勘違いね。AとBは同時に進められるから、19日もかからないの。

第2章 最早結合点時刻

最早結合点時刻（前から足す）
  1. 結合点1：0日目
  2. 結合点2：0＋3＝3　結合点3：0＋5＝5
  3. 結合点4：3＋6＝9、5＋2＝7
  4. 合流は大きい方 → 9
  5. 結合点5：9＋3＝12 → 全体で12日
めたん
第2章は、最早結合点時刻。その結合点から出る作業を、いちばん早く始められる時刻よ。
めたん
始まりの結合点1は0日目。ここから前へ、日数を足していくわ。
めたん
結合点2は0足す3で3。結合点3は0足す5で5。
めたん
結合点4には2本入るわ。Cの道は3足す6で9、Dの道は5足す2で7。
ずんだもん
早い方の7にすれば、工期が縮んでお得なのだ！
めたん
残念。Cが終わるのは9日目。全部終わるまで待つから、大きい方の9よ。
めたん
結合点5は9足す3で12。このプロジェクトは全体で12日ね。
ずんだもん
全体で12日かかるのだ。

第3章 最遅結合点時刻とクリティカルパス

最遅結合点時刻（後ろから引く）
  1. 結合点5：12（最早と同じ）
  2. 結合点4：12−3＝9
  3. 結合点3：9−2＝7　結合点2：9−6＝3
  4. 結合点1：3−3＝0、7−5＝2
  5. 分かれ目は小さい方 → 0
めたん
第3章は、最遅結合点時刻。工期を遅らせず、その結合点に到達できる最も遅い時刻よ。
めたん
今度は後ろから。最後の結合点5は、最早と同じ12にするわ。
めたん
結合点4は、12からEの3を引いて9。
めたん
結合点3は9からDの2を引いて7。結合点2は9からCの6を引いて3。
めたん
結合点1からは2本出ているわ。2の方は3ひく3で0、3の方は7ひく5で2。
めたん
後ろから引くときは、分かれ目で小さい方を取るの。だから0よ。
ずんだもん
前からは大きい方、後ろからは小さい方。反対なのだ。
余裕とクリティカルパス
  1. 結合点の余裕＝最遅 − 最早（結合点3：7−5＝2）
  2. B・D の道は合わせて2日まで遅れても全体は12日
  3. 工期を決める最長の経路＝クリティカルパス
  4. A→C→E：3＋6＋3＝12（最長）
  5. 短縮するならクリティカルパスの作業
めたん
ここで、最早と最遅を比べるわ。
めたん
結合点3は、最早が5で最遅が7。この差の2日が、この結合点の余裕よ。
ずんだもん
差の2日が余裕なのだ。
めたん
BとDの道は、合わせて2日まで遅れても、全体は12日のままなの。
ずんだもん
余裕が2日あるなら、Bの担当は2日お昼寝できるのだ！
めたん
ふふ、寝坊は困るわね。
めたん
工期を決める最長の経路が、クリティカルパスよ。
めたん
この例ではA、C、E。3足す6足す3で12日よ。
めたん
この経路のどれかが1日遅れると、全体も1日遅れるの。
めたん
だから工期を縮めたいときは、クリティカルパスの作業を短くするのよ。
めたん
人員などを増やし、追加費用をかけて工期を短縮するのがクラッシングよ。
ずんだもん
短縮には追加費用をかけるのだ。
めたん
本来は順番に行う作業を、一部重ねて進めるのがファストトラッキングよ。
ずんだもん
Bを短くしても、全体は縮まないのだ。

第4章 EVMの3つの値

EVM の3つの値（と BAC）
  1. PV：今日までに予定した作業分の予算額
  2. EV：今日までに実際に進んだ作業分の予算額
  3. AC：今日までに実際にかかった額
  4. BAC：プロジェクト全体の予算
めたん
第4章は、コストと進み具合の計算。EVMよ。
ずんだもん
EVは電気自動車のことなのだ！
めたん
ふふ、走り出しそうね。
めたん
EVMは、作業の進み具合をお金の量に直して、予定や実際と比べる方法よ。
めたん
PVはプランドバリュー。今日までに予定した作業分の予算額よ。
めたん
EVは、今日までに実際に進んだ作業分の予算額よ。
めたん
ACは実コスト。今日までに、実際にかかった額よ。
めたん
そしてBACは完成時総予算。プロジェクト全体の予算よ。
ずんだもん
使ったお金のACが予算より少なければ、順調なのだ！
めたん
それだけでは分からないわ。お金を使っていないのは、作業が進んでいないからかもしれないの。
めたん
だから、実際に進んだ作業分の予算額、EVを物差しにして比べるのよ。

第5章 SPI・CPIとEAC

比べる相手と指数
  1. 日程：EV と PV　SPI＝EV÷PV
  2. コスト：EV と AC　CPI＝EV÷AC
  3. 1未満：SPIは予定より遅れ／CPIはAC＞EV
  4. 1超：SPIは予定より進み／CPIはAC＜EV
  5. 今のコスト効率が続く場合：EAC＝AC＋（BAC−EV）÷CPI
めたん
第5章は、SPIとCPI、そしてEAC。
めたん
日程は、EVとPVを比べるわ。EVわるPVが、スケジュール効率指数、SPI。
めたん
コストは、EVとACを比べる。EVわるACが、コスト効率指数、CPIよ。
ずんだもん
SPIは、PVわるEVなのだ！
めたん
逆よ。どちらも、EVが上。わられる側がEVと覚えてね。
めたん
SPIが1未満なら予定より遅れ。CPIが1未満なら、進んだ作業分の予算額より実コストが多いの。
めたん
SPIが1超なら予定より進み。CPIが1超なら、進んだ作業分の予算額より実コストが少ないわ。
めたん
今のコスト効率が続くときの完成時総コスト見積り、EACはこの式。
めたん
残りの作業の予算、BACひくEVを、CPIでわって、ACに足すのよ。
例（作り話）BAC 200万円
  1. PV 100、EV 80、AC 64（万円）
  2. SPI＝80÷100＝0.8 → 遅れ
  3. CPI＝80÷64＝1.25 → 進んだ作業分の予算額より実コストが少ない
  4. 残り120÷1.25＝96
  5. EAC＝64＋96＝160万円
めたん
例で確かめるわ。これも作り話。完成時総予算は200万円よ。
めたん
今日の時点で、PVが100、EVが80、ACが64万円。
めたん
SPIは80わる100で0.8。1より小さいから、予定より遅れているわ。
めたん
CPIは80わる64で1.25。進んだ作業分の予算額80万円に対して、実コストは64万円ね。
ずんだもん
日程は遅れていても、コスト効率は良いのだ。両方を見るのだ。
めたん
残りの作業の予算は200ひく80で120万円。今の効率が続けば、1.25でわって96万円よ。
めたん
EACは、64足す96で160万円。予算の200より少ない見込みね。

期間10日間のプロジェクトの5日目の終了時点で，BAC 100，PV 50，EV 40，AC 60（万円）である。この時点でのコスト効率が今後も続くとしたとき，完成時総コスト見積り（EAC）は何万円か。
  • ア　110
  • イ　120
  • ウ　135
  • エ　150
答えを見るエ　150
出典：令和4年度 春期 応用情報技術者試験 午前 問51（要約・表を文で表記）
めたん
4問目は令和4年度春期の午前、問51。10日間のうち、5日目の終わりの状況よ。
めたん
コスト効率が今後も続くとき、EACは何万円か。5秒で考えてみて。
めたん
答えはエ、150万円よ。
解き方
  1. CPI＝EV÷AC＝40÷60＝3分の2
  2. 残りの作業の予算：BAC−EV＝100−40＝60万円
  3. 残りにかかる額：60÷3分の2＝90
  4. EAC＝60＋90＝150 → エ
  5. AC＋残り60＝120（イ）は効率を無視
めたん
CPIは、EVの40わるACの60で、3分の2。
めたん
残りの作業の予算は、BACの100ひくEVの40で60。
めたん
今の効率だと、60を3分の2でわって90かかるわ。
めたん
すでに使ったACの60に足して、150万円。エね。
ずんだもん
