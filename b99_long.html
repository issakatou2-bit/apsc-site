第2章 DNS をもう一歩

DNSの名前解決とレコードの例
正引きと逆引き
正引き：名前 → IP アドレス／逆引き：IP アドレス → 名前
A レコード
ホスト名に対応する IPv4 アドレス
MX レコード
そのドメインのメールを受け取るサーバ
CNAME レコード
ホスト名の別名
出典：令和6年度 秋期 応用情報技術者試験 午前 問33（逆引き・レコード・リゾルバ）。Aレコードとキャッシュは一般的な説明
めたん
第2章は、DNSをもう一歩。ホスト名とIPアドレスを結び付けるしくみだったわね。
めたん
名前からIPアドレスを調べるのが正引き。IPアドレスから名前を調べるのが逆引きよ。
めたん
DNSサーバには、レコードという形で情報が登録されているの。
めたん
Aレコードは、ホスト名に対応するIPv4アドレス。
めたん
MXレコードは、そのドメインのメールを受け取るサーバを示すの。
めたん
CNAMEレコードは、ホスト名の別名よ。
めたん
NSレコードは、そのドメインの情報を管理する権威DNSサーバを示すの。
ずんだもん
管理するサーバを示すのだ。
めたん
調べた答えは、決められた有効期間内なら、キャッシュを使って答えられるわ。

第4章 HTTP と cookie

HTTP のやり取り
リクエスト
ブラウザ → サーバ。例：GET（取得）、POST（送信）
レスポンス
サーバ → ブラウザ。例：200（成功）、404（見つからない）
cookie とセッション ID
HTTP は前のやり取りを覚えないので、cookie などで続きを伝える
めたん
第4章は、HTTP。WebブラウザとWebサーバのやり取りの決まりよ。
めたん
ブラウザが、リクエストを送る。ページを取ってくるならGET、フォームの内容を送るならPOSTなどね。
めたん
サーバが、レスポンスを返す。結果の番号が付いていて、200なら成功、404なら見つからない、よ。
ずんだもん
404は、見たことがあるのだ。
めたん

ずんだもん

cookieでは、サーバから受け取った小さな情報を、条件に合うリクエストで送り返すの。

めたん

第5章 メールのしくみ

メールのプロトコル
SMTP
メールを送る。サーバからサーバへリレーして届ける
POP3
端末に取り込む。設定によってサーバにも残せる
IMAP4
サーバ上のメールを読む・整理する。既読状態も同期できる
MIME と base64
添付ファイルや日本語を送るためのしくみ。base64 で約 4/3 倍に
出典：IPA シラバス Ver.7.2 中分類10 電子メール（配送の仕組み・関連用語）／令和7年度 春期 午前 問34（base64の転送量）。各方式の詳細は一般的な説明
めたん
第5章は、メール。メールは、サーバからサーバへ、リレーのように運ばれるの。
めたん
送るときに使うのがSMTP。自分の端末からサーバへ、サーバから相手のサーバへ、と送るわ。
めたん
相手のサーバを探すときに、さっきのMXレコードを使うのよ。
めたん
POP3はメールを端末に取り込む方式。設定によってはサーバにも残せるわ。
めたん
IMAP4は、メールをサーバに置いたまま、読んだり整理したりするの。
ずんだもん
スマホとパソコンの両方で読むなら、IMAP4が便利なのだ。
めたん
既読・未読の状態や、メールの整理を端末間で同期できるわ。
めたん
MIMEは、添付ファイルや日本語などを、メールで送れるようにするしくみ。
めたん
base64で符号化すると、3バイトが4文字になり、大きさは約4/3倍になるわ。
めたん
30キロバイトの画像なら、約40キロバイトになる計算ね。
ほかのプロトコル（シラバスの用語例から）
FTP
ファイル転送。データ用と制御用に別のポート番号
NTP
時刻を合わせる
HTTPS
HTTP over TLS。通信を暗号化する
出典：シラバス Ver.7.2、令和7年度 春期 応用情報技術者試験 午前 問33（要約）
めたん
ほかのプロトコルも少し見ておきましょう。
めたん
FTPは、ファイルを転送するプロトコル。データ用と制御用で、別のポート番号を使うのが特徴よ。
めたん
NTPは、機器どうしの時刻を合わせるプロトコルね。

過去問に挑戦

DNS に関する記述のうち、適切なものはどれか。
  • ア　DNS サーバのホスト名を登録するレコードを MX レコードという。
  • イ　DNS サーバに問い合わせを行うソフトウェアをレゾリューションという。
  • ウ　IP アドレスに対応するホスト名を調べることを逆引きという。
  • エ　ホスト名に対し別名を登録するレコードを NS レコードという。
答えを見るウ　IP アドレスに対応するホスト名を調べることを逆引きという。
出典：令和6年度 秋期 応用情報技術者試験 午前 問33
めたん
過去問に挑戦。令和6年度秋期の午前、問33よ。
めたん
DNSに関する記述のうち、適切なものはどれか。
ずんだもん
レコードの名前がたくさん出てくるのだ。
めたん
答えはウ。IPアドレスに対応するホスト名を調べるのが、逆引きよ。
めたん
アのDNSサーバを示すのはNSレコード。MXはメールのサーバだったわね。
めたん
エの別名を登録するのは、CNAMEレコードよ。
めたん
イの、問い合わせをするソフトウェアは、リゾルバと呼ぶわ。

まとめ

ここだけ覚える
  1. URL のポート番号は、ホスト名の直後に「:」で書く
  2. DNS：正引きは名前→IP、逆引きは IP→名前。MX はメール、CNAME は別名
  3. DHCP：設定を自動で配る。端末へのDHCPサーバのアドレスの事前設定は不要
  4. HTTP は前を覚えない → cookie・セッション ID
  5. SMTPは送る、POP3は端末に取り込む、IMAP4はサーバ上のメールや既読状態を管理する
めたん
まとめよ。URLのポート番号は、ホスト名の直後に、コロンで書く。
めたん
DNSは、正引きと逆引き。MXはメール、CNAMEは別名。
めたん
DHCPは設定を自動で配る。端末にDHCPサーバのアドレスを事前設定する必要はない。
めたん
HTTPは前を覚えないから、cookieやセッションIDを使う。
めたん
SMTPは送る、POP3は端末に取り込む、IMAP4はサーバ上のメールや既読状態を管理する。
